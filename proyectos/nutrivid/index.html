nutrivid.

Nutrivid es una tienda online desarrollada para una dietética con múltiples sucursales, pensada para facilitar la consulta de productos y la realización de pedidos de forma rápida y sencilla.

01 · Contexto

Varias sucursales, ninguna web propia.

El proyecto surge a partir de una situación real de una dietética que cuenta con varias sucursales pero no dispone de una página web propia.

A partir de esta necesidad, se desarrolló una propuesta digital que busca centralizar la información de los productos, facilitar su consulta y mejorar la experiencia de compra de los clientes.

1
Elegí productos
El cliente selecciona una sucursal y consulta el catálogo con el stock de esa sucursal.
2
Enviá el pedido
Arma el carrito, ajusta cantidades y revisa el total antes de enviarlo.
3
Confirmamos por WhatsApp
El pedido llega por chat y la dietética coordina la compra con el cliente.

Mobile + pedidos por WhatsApp

Armá tu pedido acá y lo coordinamos por WhatsApp.

El sistema permite preparar un pedido desde el carrito y enviarlo mediante WhatsApp. Esto facilita la comunicación entre el cliente y la dietética para coordinar la compra.

04 · Roles de usuario

Tres tipos de acceso

Panel
Administrador

Cuenta con acceso a las principales funcionalidades de administración del sistema. Puede gestionar productos, categorías, sucursales, usuarios y stock.

Panel
Usuario de panel

Puede acceder a las funcionalidades administrativas correspondientes según sus permisos y sucursales asignadas.

Tienda
Cliente

Consulta el catálogo, selecciona una sucursal, busca y filtra productos, los agrega al carrito, prepara un pedido y lo envía mediante WhatsApp.
